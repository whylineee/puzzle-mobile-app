# Puzzle Mobile App

Стартовий мобільний застосунок на Expo Router для гри-головоломки.

## Що вже готово

- Налаштований Expo/React Native проєкт
- Домашній екран для запуску гри
- Робочий екран `Sliding Puzzle` 4x4
- TypeScript та ESLint

## Запуск

```bash
npm install
npm run start
```

Швидкі команди:

```bash
npm run ios
npm run android
npm run web
```

## Структура

- `app/index.tsx` — стартовий екран
- `app/game.tsx` — базова ігрова механіка
- `app/_layout.tsx` — маршрути Expo Router

## Ідеї для наступних кроків

- додати таймер і рекорд
- зберігати прогрес гри
- додати рівні складності
